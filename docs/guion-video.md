# Video de Campus Tareas

Integrantes: Antony Piero Solorzano Zegarra y Adriana Rafaela Laos Gonzáles.

Duración publicada: 4 minutos. Resolución: 1920 × 1080. Explicaciones en pantalla, sin narración.

Enlace público: https://www.youtube.com/watch?v=YAXXFRYB4Rk

El video presenta la estructura del proyecto, la configuración de Firebase, el modelo de documentos, las operaciones CRUD, las reglas por usuario y el despliegue en GitHub Pages con GitHub Actions. Incluye capturas reales del registro, la edición, el cambio de estado, la persistencia al recargar y la eliminación de una tarea en la app publicada.
